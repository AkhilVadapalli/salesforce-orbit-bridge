# Project Milestones

## Milestone 1: Problem definition

- identify a real business pain point
- define the support workflow challenge
- write user stories and expected value

## Milestone 2: Architecture design

- define Salesforce objects and dependencies
- set the integration boundaries
- decide where automation and AI fit

## Milestone 3: Core logic

- build the Apex triage service
- establish recommendation output structure
- prove the logic through unit tests

## Milestone 4: User interface

- create an LWC summary panel
- show triage suggestions in a usable format
- improve actionability for support agents

## Milestone 5: Workflow automation

- outline queue routing rules
- define escalation conditions
- create a realistic support automation flow

## Milestone 6: Portfolio polish

- add demo scenario and screenshots
- write business impact section
- highlight why this matters in the AI era
